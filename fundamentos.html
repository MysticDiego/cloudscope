01 / Comprender la nube

Una nube.
Una base muy real.

Empieza por la idea central: acceder a recursos de computación como servicios, sin tener que disponer de toda la infraestructura en tu propio equipo.

En esta página El concepto Características Cómo funciona Conceptos clave

La idea esencial

Recursos disponibles
cuando los necesitas.

Cloud Computing permite solicitar capacidad de procesamiento, almacenamiento y otros recursos a través de una red, con aprovisionamiento ágil.

La palabra «nube» describe una forma de acceder y administrar recursos. Detrás existen equipos, centros de datos, conexiones y personas que mantienen los servicios.

Una distinción útil

Guardar un archivo en otro equipo no describe, por sí solo, todo el modelo de nube. También importan la disponibilidad bajo demanda, la agrupación de recursos y la capacidad de ajustar y medir su uso.

Las cinco características esenciales

¿Qué hace que sea nube?

El NIST identifica cinco características para comprender este modelo.

01

Autoservicio bajo demanda

Solicitar recursos cuando se necesitan, sin gestionar manualmente cada solicitud con el proveedor.

02

Acceso por la red

Utilizar los servicios desde dispositivos compatibles mediante mecanismos de acceso habituales.

03

Recursos compartidos

Agrupar capacidad para atender a distintos usuarios con asignación según la demanda.

04

Elasticidad rápida

Aumentar o reducir la capacidad disponible para responder a cambios en el uso.

05

Servicio medido

Supervisar el consumo de recursos para dar visibilidad a usuarios y proveedores.

Fuente: NIST SP 800-145: The NIST Definition of Cloud Computing.

Una solicitud, de principio a fin

¿Qué sucede al utilizarla?

  1. Solicitas una acción.Abres una aplicación o pides un archivo desde tu dispositivo.
  2. La solicitud viaja por una red.La conexión permite comunicarse con el servicio correspondiente.
  3. El servicio realiza el trabajo.Los recursos disponibles procesan la solicitud o recuperan información.
  4. Recibes el resultado.El navegador o la aplicación presenta la respuesta para que continúes.

Descripción introductoria basada en Google Cloud: funcionamiento de Cloud Computing.
